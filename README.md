# Интерактивное резюме — Игорь Яшкузин

Статический сайт для GitHub Pages, построенный на Jekyll. Используются Markdown (`index.md`), конфигурация (`_config.yml`), пользовательский layout, CSS и небольшой JavaScript без сторонних JS-библиотек.

## Публикация на GitHub Pages

### Рекомендуемый вариант: корневая страница профиля

1. На GitHub создай публичный репозиторий с точным именем **`at0m1cc.github.io`**.
2. Загрузи **все файлы и папки из этого комплекта в корень репозитория**, а не саму папку `igory_resume_site` целиком.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохрани настройки.
5. Дождись завершения сборки GitHub Pages и открой `https://at0m1cc.github.io/`.
6. Проверь ссылку в приватном/инкогнито-окне и протестируй кнопки, репозитории и навигацию.

Адрес `https://at0m1cc.github.io/` является ожидаемым адресом для репозитория с именем `at0m1cc.github.io`; до фактической публикации и проверки он не считается подтверждённым.

## Интерактивность

- Переключение светлой и тёмной темы с сохранением выбора в браузере.
- Кнопка «Сохранить в PDF» вызывает диалог печати браузера: в нём можно выбрать «Сохранить как PDF».
- Кнопка копирования адреса электронной почты.
- Раскрывающиеся описания проектов (`details/summary`).
- Адаптивная компоновка для мобильных устройств и якорная навигация.

## Файлы

- `index.md` — содержимое резюме.
- `_config.yml` — настройки Jekyll/GitHub Pages.
- `_layouts/default.html` — HTML-оболочка страницы.
- `assets/css/style.scss` — стили (GitHub Pages обрабатывает SCSS в CSS).
- `assets/js/main.js` — интерактивные элементы.

## Перед сдачей отчёта

В отчёте укажи фактическую опубликованную ссылку, сделай скриншоты опубликованной страницы со всеми разделами (либо сохрани страницу через печать в PDF). Не отмечай проверку публичного доступа как выполненную, пока не проверишь URL без входа в GitHub.
